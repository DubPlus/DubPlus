### Description

A extension for added features and customizations to improve your QueUp.net experience

Features include:

- AFK Auto-respond
- Auto AFK
- AutoVote
- Collapsible Images
- Community Theme
- Custom Background
- Custom CSS
- Custom Mentions
- DJ Notification
- Dub Info on Hover
- Flip Interface
- FullScreen
- Grab Response
- Hide Video
- Notify on Mentions
- Notify on PM
- Snooze Video (Hides just the video for 1 song)
- Rain Animation
- Snow Animation
- SpaceBar Mute
- Split Chat
- Warn on navigation
- ETA (an estimate on when you're song will play)
- Hide Avatars
- Hide Background
- Pin Menu

More info at https://dub.plus
